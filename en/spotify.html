Academic Project · Business Intelligence

Spotify Dashboard

Development of an interactive dashboard using music data to analyze track popularity, explore artist performance and track listening trends over time.

Power BI Dimensional Modeling Data Preparation KPIs
01 / CONTEXT

The Project

Developed as part of an academic project in Business Intelligence, this project is based on a dataset of the most-streamed Spotify tracks in 2024, containing approximately 4,600 records.

The objective was to transform raw data into a dashboard that allows users to explore listening activity from different perspectives: artists, albums, tracks and time periods.

02 / DASHBOARD

Artist Analysis

The main page allows users to select an artist and explore their performance through several indicators and visualizations. It includes total Spotify streams, average Track Score, monthly listening trends and the distribution of streams by album.

Power BI dashboard — Artist Analysis.
03 / DATA MODELING

Data Structuring

The data was organized using a star schema, with a fact table connected to three dimension tables: Artist, Track and Time. This structure makes it easier to analyze indicators across the different dimensions of the dataset.

Star schema — Power BI data model.
04 / EXPLORATION

Hits of the Month

A second page, accessible through drill-through from the report, provides a view focused on a specific month. It highlights a featured track of the month, the five most represented artists and a detailed ranking of tracks.

"Hits of the Month" page — detailed exploration by time period.
