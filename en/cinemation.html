01 / CONTEXT

The Project

CINEMATION is an academic project dedicated to animated cinema. The objective was to design a one-page website bringing together informative content and visualizations about this world.

The project brief included the integration of interactive charts using JavaScript libraries such as Chart.js or Plotly, as well as the creation of motion design visualizations.

The website explores several aspects of animated cinema: animation techniques, studios, films, box office revenue and awards.

CINEMATION website homepage.
02 / DATA VISUALIZATION

Visualizing Data

Two interactive charts were integrated into the website using Chart.js to present and compare different datasets related to animated cinema.

Production Budgets and Box Office Revenue

Comparison of production budgets and worldwide box office revenue for several animated films, highlighting the relationship between investment and box office performance.

Film Releases in Theaters

Changes in the number of animated films released in French cinemas between 2013 and 2022, broken down by geographical origin.

Comparison of production budgets and worldwide box office revenue.

03 / DEVELOPMENT

Website Design

The website design involved organizing the content, structuring the different sections and integrating them into a one-page interface.

A visual identity consistent with the animated cinema theme was developed, combining layout, graphic elements and animations.

In addition to the interactive charts, the project also includes motion design visualizations combining data, animation and graphic elements.

Examples of visual representations created using motion design.
