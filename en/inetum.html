01 / CONTEXT

The Assignment

This internship at Inetum focused on automating the processing of employment market data in the fields of Data and artificial intelligence.

I developed Python scripts to collect job offers from several platforms, enrich their information using a language model API (LLM), and then extract and structure data from CVs in JSON format.

02 / DATA COLLECTION

Job Offer Collection

The objective was to build a database of job offers published on the Moroccan market in the fields of Data and artificial intelligence. To achieve this, I developed Python scripts to collect job postings from four employment platforms: Stagiaires.ma, Jobiglo, Rekrute and Bayt.

Depending on each website's structure, the scripts use Requests and BeautifulSoup or Selenium. They retrieve information such as job titles, companies, locations, contract types and descriptions, then filter the listings matching the targeted fields.

01

Data Collection from Platforms

Browsing search result pages, retrieving relevant job postings and accessing detailed pages to extract additional information.

02

Cleaning and Standardization

Filtering job titles, cleaning descriptions, extracting specific information using regular expressions and standardizing fields such as required experience.

03

File Consolidation

Merging the four CSV files, removing duplicates and preserving the original source of each job posting.

04 / AUTOMATION

CV Information Extraction

Development of a Python script to extract information from Word-format CVs. The script processes documents placed in a folder and gathers the detected information into a JSON file.

The extraction relies on regular expressions (Regex) and detection rules designed to handle different document sections and layouts. The extracted information is organized into education, technical skills, professional experience and languages.

01

Reading Word Documents

Reading CV paragraphs and tables using the python-docx library.

02

Rule-Based Extraction

Detecting sections and extracting information, including skills and their categories, using rules and regular expressions.

03

Generating a JSON File

Gathering the detected information into an organized structure to make it easier to consult and use later.
