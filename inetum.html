Stage · Data & IA

Collecte et structuration de données

Développement de scripts Python pour collecter des offres d’emploi au Maroc, explorer le marché de l’emploi dans les domaines de la Data et de l’intelligence artificielle, puis analyser et structurer des informations à l’aide d’une API LLM. Le stage comprenait également l’extraction d’informations de CV au format JSON.

Inetum Python Web scraping API LLM CSV & JSON
01 Contexte

La mission

L’objectif était de constituer une base d’offres d’emploi publiées au Maroc afin d’explorer les profils recherchés sur le marché de la Data et de l’intelligence artificielle. Cette collecte devait permettre de disposer d’informations exploitables sur les postes, les entreprises, les compétences et les niveaux d’expérience demandés.

En parallèle, j’ai travaillé sur l’analyse et l’enrichissement des offres par une API de modèle de langage (LLM), ainsi que sur l’extraction d’informations issues de CV au format Word pour générer des données structurées.

Explorer le marché

Collecter des annonces issues de plusieurs plateformes d’emploi afin de constituer une base de données sur les métiers de la Data et de l’IA au Maroc.

Structurer l’information

Transformer des contenus textuels en données organisées, exploitables pour faciliter leur analyse et leur traitement.

02 Collecte

Collecte d’offres d’emploi

J’ai développé des scripts Python pour récupérer des offres d’emploi dans les domaines de la Data et de l’IA publiées sur plusieurs plateformes marocaines ou proposant des annonces localisées au Maroc. Ce périmètre géographique permettait d’étudier les profils recherchés sur ce marché.

03 Enrichissement

Analyse et enrichissement avec une API LLM

Une API de modèle de langage a été utilisée pour analyser le contenu textuel des offres et en extraire des informations complémentaires à partir de consignes définies. L’objectif était de rendre les descriptions plus faciles à exploiter en organisant certaines informations dans des champs structurés.

  • 01
    Analyse du contenu

    Transmission du texte des annonces à l’API afin d’en analyser le contenu et d’identifier les informations pertinentes.

  • 02
    Extraction des informations

    Identification de champs complémentaires à partir de consignes définies pour le traitement.

  • 03
    Structuration des résultats

    Organisation des informations produites dans des champs structurés afin de faciliter leur exploitation.

04 Automatisation

Extraction d’informations de CV

J’ai également développé un script Python permettant de traiter des CV au format Word. Le script lisait les documents, repérait certaines informations à l’aide de règles et d’expressions régulières, puis les organisait dans un fichier JSON.

  • 01
    Lecture des documents Word

    Récupération du texte des documents à traiter.

  • 02
    Extraction par règles

    Repérage et extraction de certaines informations à partir de règles et d’expressions régulières.

  • 03
    Génération du fichier JSON

    Organisation des informations extraites dans une structure JSON afin de permettre leur réutilisation par un autre traitement.
