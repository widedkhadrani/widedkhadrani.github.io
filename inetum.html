Collecte et structuration de données

Travail autour de la collecte d’offres d’emploi, de leur analyse et de l’extraction d’informations à partir de CV. Utilisation de Python et d’outils de traitement automatisé pour organiser les données dans des formats structurés.

Inetum Python Traitement de données API LLM
01 / CONTEXTE

La mission

Cette expérience chez Inetum m’a permis de travailler sur plusieurs étapes du traitement de données : collecte d’informations issues de sites d’emploi, analyse et enrichissement des offres, puis extraction d’informations contenues dans des CV.

Les travaux reposaient sur des scripts Python permettant d’automatiser certaines tâches et de transformer des données issues de différentes sources en fichiers structurés.

Collecter

Récupérer des informations sur des offres d’emploi publiées sur plusieurs sites.

Structurer

Organiser les informations extraites pour faciliter leur lecture et leur exploitation.

02 / COLLECTE

Collecte d’offres d’emploi

Développement de scripts Python pour collecter des offres d’emploi publiées sur plusieurs plateformes. Les scripts récupèrent notamment les intitulés de postes, les entreprises, les localisations et les descriptions, selon les informations disponibles sur chaque site.

Les données collectées sont ensuite nettoyées et organisées dans des fichiers CSV, avec des règles de filtrage et de déduplication adaptées aux données récupérées.

01

Collecte automatisée

Utilisation de requêtes HTTP, de BeautifulSoup et de Selenium selon le fonctionnement des plateformes.

02

Nettoyage des données

Traitement des descriptions, filtrage des offres pertinentes et suppression des doublons identifiés.

03

Export des résultats

Organisation des informations collectées dans des fichiers CSV pour les étapes de traitement suivantes.

03 / ENRICHISSEMENT

Analyse et enrichissement avec une API LLM

Mise en place d’un traitement utilisant une API de modèle de langage pour analyser les informations présentes dans les offres d’emploi et compléter les données collectées.

À partir des intitulés, des descriptions et des informations disponibles, le traitement vise notamment à identifier les compétences, les catégories de compétences, le type de poste, le secteur d’activité et certaines informations liées au contrat ou à l’expérience demandée.

01

Analyse du contenu

Transmission des informations utiles des offres à l’API afin d’en analyser le contenu textuel.

02

Extraction des informations

Identification de champs complémentaires à partir de consignes définies pour le traitement.

03

Structuration des résultats

Organisation des informations produites dans des champs structurés, puis traitement des fichiers pour regrouper et filtrer les données.

04 / AUTOMATISATION

Extraction d’informations de CV

Développement d’un script Python destiné à extraire des informations à partir de CV au format Word. Le script traite trois documents placés dans un dossier et regroupe les informations détectées dans un fichier JSON.

L’extraction s’appuie sur des expressions régulières et des règles de détection tenant compte des différentes rubriques et structures des documents.

01

Lecture des documents Word

Parcours du contenu textuel et de certains tableaux pour repérer les informations utiles.

02

Extraction par règles

Repérage des formations, compétences, langues et expériences professionnelles à l’aide de règles et d’expressions régulières.

03

Génération d’un fichier JSON

Regroupement des informations extraites dans une structure organisée pour faciliter leur exploitation ultérieure.

05 / COMPÉTENCES

Outils & méthodes

Cette expérience m’a permis de mettre en pratique des techniques de collecte, de nettoyage et de structuration de données, ainsi que des méthodes d’extraction d’informations à partir de contenus textuels.
