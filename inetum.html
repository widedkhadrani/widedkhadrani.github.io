Collecte et structuration de données

Développement de scripts Python pour collecter des offres d’emploi par web scraping, analyser et enrichir les données à l’aide d’une API LLM, et extraire des informations de CV pour les structurer au format JSON.

Inetum Python Web scraping API LLM
01 / CONTEXTE

La mission

Cette expérience chez Inetum m’a permis de travailler sur plusieurs étapes du traitement de données : collecte d’offres d’emploi par web scraping, analyse et enrichissement de leur contenu, puis extraction d’informations contenues dans des CV.

Ces travaux reposaient sur des scripts Python visant à automatiser certaines tâches et à transformer des informations issues de différentes sources en données structurées.

Collecter

Récupérer des informations sur des offres d’emploi publiées sur plusieurs plateformes grâce au web scraping.

Structurer

Nettoyer, organiser et enrichir les informations extraites pour faciliter leur exploitation.

02 / COLLECTE

Collecte d’offres d’emploi

L’objectif était de constituer une base d’offres d’emploi publiées sur le marché marocain dans les domaines de la Data et de l’intelligence artificielle. Pour cela, j’ai développé des scripts Python permettant de collecter des annonces depuis quatre plateformes d’emploi : Stagiaires.ma, Jobiglo, Rekrute et Bayt.

Selon la structure des sites, les scripts s’appuient sur Requests et BeautifulSoup ou sur Selenium. Ils récupèrent notamment les intitulés de postes, les entreprises, les localisations, les contrats et les descriptions, puis filtrent les annonces correspondant aux domaines recherchés.

01

Collecte sur les plateformes

Parcours des pages de résultats, récupération des annonces pertinentes et consultation des pages détaillées pour extraire les informations complémentaires.

02

Nettoyage et harmonisation

Filtrage des intitulés, nettoyage des descriptions, extraction de certaines informations par expressions régulières et harmonisation de champs comme l’expérience.

03

Consolidation des fichiers

Regroupement des quatre fichiers CSV, suppression des doublons et conservation de la source d’origine de chaque annonce.

03 / ENRICHISSEMENT

Analyse et enrichissement avec une API LLM

Mise en place d’un traitement utilisant une API de modèle de langage (LLM) pour analyser le contenu des offres d’emploi et compléter les informations collectées.

À partir des intitulés, des descriptions et des autres informations disponibles, le traitement vise notamment à identifier les compétences, leurs catégories, le type de poste, le secteur d’activité et certaines informations liées au contrat ou à l’expérience demandée.

01

Analyse du contenu

Transmission des informations des offres à l’API accompagnées de consignes précisant les éléments à identifier.

02

Extraction des informations

Identification de champs complémentaires à partir du contenu textuel des offres.

03

Structuration des résultats

Organisation des informations extraites dans des champs structurés, puis regroupement et filtrage des fichiers obtenus.

04 / AUTOMATISATION

Extraction d’informations de CV

Développement d’un script Python destiné à extraire des informations à partir de CV au format Word. Le script traite trois documents placés dans un dossier et regroupe les informations détectées dans un fichier JSON.

L’extraction s’appuie sur des expressions régulières (Regex) et des règles de détection tenant compte des différentes rubriques et structures des documents.

01

Lecture des documents Word

Parcours du texte et de certains tableaux des CV pour repérer les informations utiles.

02

Extraction par règles

Repérage des formations, compétences, langues et expériences professionnelles à l’aide de règles et d’expressions régulières.

03

Génération d’un fichier JSON

Regroupement des informations extraites dans une structure organisée pour faciliter leur exploitation ultérieure.

Outils & méthodes
